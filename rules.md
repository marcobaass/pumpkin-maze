Goal of the game:

- Collecting all candys

Player looses:

- If the pumpkin falls off the tray
- If the pumpkin falls into a grave(hole)
- If the pumpkin hits a ghost (moving)
- If the pumpkin hits a skeleton (stationary)

Items

- Pumpkin
- Candy (collecting)
- Ghosts (moving)
- Skeleton (stationary)
- Candles
- Grave (holes)
